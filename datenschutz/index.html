3. Besuch unserer Website

4. Kontakt- und Schnupperanmeldung

Auf unserer Website besteht die Möglichkeit, sich über ein Formular für ein Schnuppertreffen anzumelden.

Die von Ihnen eingegebenen Daten werden ausschliesslich zur Bearbeitung Ihrer Anfrage bzw. Anmeldung verwendet und per E-Mail an die zuständige Person des Modellbahn-Treffs übermittelt.

Je nach Formular können folgende Daten verarbeitet werden:

  • Name
  • E-Mail-Adresse
  • Telefonnummer
  • Mitteilungstext
  • weitere von Ihnen angegebenen Angaben

Die Daten werden nicht an Dritte weitergegeben und nur so lange aufbewahrt, wie dies für die Bearbeitung der Anfrage erforderlich ist.

Erfolgt eine Übernahme werden die Kontaktdaten in unserer Adressliste abgelegt.
Erfolgt ein Austritt werden die Kontaktdaten innerhalb eines Monats gelöscht.
